## 1. Admission Webhooks ✅

### Overview

Admission webhooks intercept MigrationJob creation requests before they reach the API server, providing:

- **Validation** - Reject invalid jobs before creation
- **Mutation** - Apply sensible defaults automatically
- **Resource Quotas** - Enforce namespace limits
- **Worker Capacity** - Check if workers are available

### Architecture

```
User creates MigrationJob
    ↓
Kubernetes API Server
    ↓
Webhook Server (HTTPS)
    ├─→ Validation Webhook (/validate)
    │   ├─ Validate spec
    │   ├─ Check quotas
    │   ├─ Check worker capacity
    │   └─ Allow / Deny
    │
    └─→ Mutation Webhook (/mutate)
        ├─ Add default priority (50)
        ├─ Add default timeout (2h)
        ├─ Add default retry policy
        └─ Add creation timestamp
    ↓
MigrationJob created (if validated)
```

### Validation Rules

| Rule | Check | Failure Message |
|------|-------|----------------|
| **Required Fields** | operation, image.path, image.format | "field is required" |
| **Valid Operation** | Must be: inspect, convert, offline_fix | "operation must be one of..." |
| **Valid Format** | Must be: vmdk, vdi, vhd, vhdx, qcow2, raw | "image.format must be one of..." |
| **Priority Range** | 0-100 | "priority must be between 0 and 100" |
| **Timeout Format** | Must match: \d+(s\|m\|h), max 24h | "timeout must be in format..." |
| **Retry Policy** | maxRetries: 0-5, backoff: exponential\|linear\|fixed | "retryPolicy.maxRetries must be..." |
| **Checksum Format** | Must start with "sha256:" | "checksum must start with 'sha256:'" |
| **Resource Quota** | Active jobs < 10 per namespace | "Namespace quota exceeded: 10/10" |
| **Worker Capacity** | At least 1 worker available | "No worker pods available" (warning) |

### Mutation Defaults

| Field | Default Value | Applied When |
|-------|---------------|--------------|
| `priority` | 50 | Not specified |
| `timeout` | "2h" | Not specified |
| `retryPolicy.maxRetries` | 2 | Not specified |
| `retryPolicy.backoff` | "exponential" | Not specified |
| `artifacts.output_format` | "qcow2" | artifacts exists but output_format missing |
| `metadata.annotations["hyper2kvm.io/created-at"]` | Current timestamp | Always |
| `metadata.annotations["hyper2kvm.io/webhook-version"]` | "v1.5.0" | Always |

```bash
# Test validation (should pass)
kubectl apply -f k8s/operator/examples/convert-job.yaml

# Test validation failure
cat <<EOF | kubectl apply -f -
apiVersion: hyper2kvm.io/v1alpha1
kind: MigrationJob
metadata:
  name: invalid-job
  namespace: hyper2kvm-workers

  operation: invalid_operation  # Invalid!
  image:
    path: /data/test.vmdk
    format: vmdk
EOF
# Should be rejected with validation error
```

### Webhook Failure Policies

**Validating Webhook:**
- `failurePolicy: Fail`
- If webhook is unavailable, reject all MigrationJob creations
- Ensures no invalid jobs are created

**Mutating Webhook:**
- `failurePolicy: Ignore`
- If webhook is unavailable, allow creation without mutations
- Fail-open to avoid blocking job submissions

### Example: Validation Rejection

```bash
$ kubectl apply -f invalid-job.yaml

Error from server: error when creating "invalid-job.yaml": admission webhook "validate.migrationjob.hyper2kvm.io" denied the request: Validation failed: operation must be one of: inspect, convert, offline_fix; priority must be between 0 and 100
```

### Example: Mutation Applied

```yaml
# Before mutation (user submitted):

  operation: convert
  image:
    path: /data/input/test.vmdk
    format: vmdk

# After mutation (in API server):
spec:
  operation: convert
  image:
    path: /data/input/test.vmdk
    format: vmdk
  priority: 50          # Added
  timeout: 2h           # Added
  retryPolicy:          # Added
    maxRetries: 2
    backoff: exponential

metadata:
  annotations:
```

#### Test Examples

**Validation Test:**
```python
def test_invalid_operation(self):
    """Test validation fails for invalid operation."""
    spec = {
        'operation': 'invalid_op',
        'image': {
            'path': '/data/input/test.vmdk',
            'format': 'vmdk'
        }
    }

    is_valid, errors = self.validator.validate(spec)
    assert is_valid is False
    assert any('operation must be one of' in err for err in errors)
```

**Job Assigner Test:**
```python
@pytest.mark.asyncio
async def test_assign_to_idle_worker(self):
    """Test job is assigned to idle worker."""
    self.registry.register_worker('worker-1', {}, 'node-1')
    self.registry.register_worker('worker-2', {}, 'node-2')
    self.registry.mark_worker_busy('worker-1')

    workers = [
        {'name': 'worker-1', 'ready': True},
        {'name': 'worker-2', 'ready': True}
    ]

    spec = {'operation': 'convert', 'priority': 50}
    best_worker = await self.assigner.find_suitable_worker(spec, workers)

    assert best_worker['name'] == 'worker-2'  # Prefers idle
```

## 6. Production Considerations

### High Availability

**Webhook Server:**
- Deployed with 2 replicas for HA
- Requests load-balanced across replicas
- If one replica fails, other continues serving

**Certificate Management:**
- Certificates valid for 10 years
- Rotation script included
- Stored in Kubernetes Secret

### Resource Quotas

**Default Quota:** 10 active jobs per namespace

**Customize Quota:**
Edit `hyper2kvm/operator/webhook.py`:
```python
# Change max_jobs_per_namespace
max_jobs_per_namespace = 20  # Increase to 20
```

**Webhook Health:**
