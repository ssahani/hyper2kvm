## 2. Automation Scripts ✅

### package-charts.sh

Package all Helm charts and generate repository index.

**Location**: `scripts/package-charts.sh` (300 lines)

**Features:**
- Finds all charts in `helm/` directory
- Lints each chart before packaging
- Packages charts to `.tgz` files
- Generates or updates `index.yaml`
- Verifies packaged charts (tar integrity)
- Detailed progress reporting

**Usage:**
```bash
# Package all charts to ./charts
./scripts/package-charts.sh

# Package and update existing index
./scripts/package-charts.sh --update-index

# Package to custom directory
./scripts/package-charts.sh --output-dir /tmp/charts

# Package for custom repository URL
./scripts/package-charts.sh --repo-url https://example.com/charts
```

### bump-chart-version.sh

Bump Helm chart versions following semantic versioning.

**Location**: `scripts/bump-chart-version.sh` (350 lines)

**Features:**
- Semantic versioning support (major.minor.patch)
- Updates both `version` and `appVersion` in Chart.yaml
- Dry run mode for preview
- Validates version format (X.Y.Z)
- Supports targeting specific charts or all charts

**Usage:**
```bash
# Bump patch version of all charts (1.6.0 -> 1.6.1)
./scripts/bump-chart-version.sh --type patch

# Bump minor version of operator (1.6.0 -> 1.7.0)
./scripts/bump-chart-version.sh \
  --chart hyper2kvm-operator \
  --type minor

# Bump major version (1.6.0 -> 2.0.0)
./scripts/bump-chart-version.sh --type major

# Set specific version
./scripts/bump-chart-version.sh \
  --chart hyper2kvm-operator \
  --version 2.0.0

# Dry run to preview changes
./scripts/bump-chart-version.sh --type minor --dry-run

# Don't update appVersion (chart-only changes)
./scripts/bump-chart-version.sh --type patch --no-app-version
```

## 3. GitHub Actions Workflow ✅

### Helm Release Workflow

**Location**: `.github/workflows/helm-release.yml` (150 lines)

**Triggers:**
1. **Tag Push**: Automatically triggers when pushing tags matching `v*.*.*`
   ```bash
   git tag v1.7.0
   git push origin v1.7.0
   ```

2. **Manual Workflow Dispatch**: Can be triggered manually from GitHub UI
   - Actions → Helm Chart Release → Run workflow
   - Input: Chart version (e.g., 1.7.0)

**Workflow Steps:**

```yaml
jobs:
  release-charts:
    steps:
      1. Checkout code (with full history)
      2. Configure Git (for committing to gh-pages)
      3. Install Helm 3.13.0
      4. Determine version (from tag or manual input)
      5. Lint all Helm charts (fail on any lint errors)
      6. Package charts to .cr-release-packages/
      7. Checkout gh-pages branch
      8. Copy packaged charts to gh-pages
      9. Generate/update repository index
      10. Commit and push to gh-pages
      11. Create GitHub Release with chart artifacts

  verify-release:
    needs: release-charts
    steps:
      1. Install Helm
      2. Wait for GitHub Pages deployment (60s)
      3. Add Helm repository
      4. Verify charts are searchable
      5. Verify chart metadata
```

**Permissions Required:**
```yaml
permissions:
  contents: write    # For creating releases and pushing to gh-pages
  pages: write       # For GitHub Pages deployment
  id-token: write    # For OIDC authentication
```

## 6. GitOps Integration ✅

### ArgoCD Application

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: hyper2kvm-operator
  namespace: argocd
spec:
  project: default

  source:
    chart: hyper2kvm-operator
    repoURL: https://ssahani.github.io/hyper2kvm
    targetRevision: 1.7.0
    helm:
      valueFiles:
        - values-production.yaml

  destination:
    server: https://kubernetes.default.svc
    namespace: hyper2kvm-system

  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
      - CreateNamespace=true
```

### Flux HelmRelease

```yaml
---
apiVersion: source.toolkit.fluxcd.io/v1beta2
kind: HelmRepository
metadata:
  name: hyper2kvm
  namespace: flux-system
spec:
  interval: 10m
  url: https://ssahani.github.io/hyper2kvm

---

kind: HelmRelease

  name: hyper2kvm-operator
  namespace: hyper2kvm-system

  interval: 10m

    spec:
      chart: hyper2kvm-operator
      version: 1.7.0
      sourceRef:
        kind: HelmRepository

      resources:

          cpu: 200m

      enabled: true
```
