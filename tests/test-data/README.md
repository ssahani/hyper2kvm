# Test Data Directory

This directory contains generated test disk images used by the hyper2kvm test suite.

## Generated Images

The images in this directory are generated by `tests/make-test-images.py` and are used for integration testing of VMDK parsing, security features, and disk handling.

### Image Files

#### Simple Raw Disk
- **simple.raw** - 100 MiB raw disk image for basic testing

#### VMDK Descriptor/Extent Pairs
- **test.vmdk** - VMDK descriptor file (monolithicFlat)
- **test-flat.vmdk** - 100 MiB flat extent file
- Tests descriptor/extent pair validation and layout detection

#### Multi-Extent VMDK
- **test-multi.vmdk** - VMDK descriptor (twoGbMaxExtentSparse)
- **test-s001.vmdk** - First 100 MiB extent
- **test-s002.vmdk** - Second 100 MiB extent
- **test-s003.vmdk** - Third 100 MiB extent
- Tests multi-extent handling and size calculation

#### Security Test Images
- **malicious/traversal.vmdk** - Path traversal attack test (references `../../../etc/passwd`)
- **subdir-test.vmdk** + **subdir/extent.vmdk** - Legitimate subdirectory reference test
- **large.vmdk** - Large descriptor (>8 MiB) to test size limits
- **binary.vmdk** - Binary file to test descriptor detection

## Regenerating Test Images

To regenerate all test images:

```bash
cd tests
python make-test-images.py all test-data
```

To generate specific layouts:

```bash
# Simple raw disk only
python make-test-images.py simple test-data

# VMDK descriptor/extent pair
python make-test-images.py vmdk-descriptor test-data

# Multi-extent VMDK
python make-test-images.py multi-extent test-data

# Security test images
python make-test-images.py security test-data

# All images
python make-test-images.py all test-data
```

## Test Coverage

These images are used by integration tests in:
- `tests/unit/test_vmware/test_vmdk_integration.py`

The integration tests verify:
- VMDK descriptor parsing with real files
- Multi-extent VMDK handling
- Descriptor/extent pair validation
- Layout detection (descriptor vs flat vs sparse)
- Sparse vs flat disk detection
- Path traversal protection
- Subdirectory reference validation
- Large descriptor rejection
- Binary file rejection
- Extent resolution and existence checks
- Extent size validation

## Size Information

Total size of test data: ~411 MiB
- 3 × 100 MiB extent files (test-s001.vmdk, test-s002.vmdk, test-s003.vmdk)
- 1 × 100 MiB flat extent (test-flat.vmdk)
- 1 × 100 MiB raw image (simple.raw)
- ~11 MiB large descriptor (large.vmdk)
- Small descriptor and test files (~10 KiB)

All files use sparse allocation where possible to minimize actual disk usage.

## Notes

- These are test files only - they do not contain real filesystems or bootable systems
- Images are filled with zeros (sparse files)
- Security test images intentionally contain malicious patterns for security testing
- Do not use these images for production or real VM workloads
